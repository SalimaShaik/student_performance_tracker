## Student Performance Tracker
An interactive dashboard for managing student academic records and analyzing performance.

Features

Add and manage student records.
Calculate total marks and average marks.
Assign grades based on predefined thresholds.
Display student academic status.
Visualize subject-wise performance using charts.
Analyze grade distribution and student rankings.
Search students and filter records by class.
Export student records as CSV files.
Technologies: Python, Streamlit, Pandas, Plotly

Run the application

python -m streamlit run student_performance_tracker.py# student_performance_tracker
